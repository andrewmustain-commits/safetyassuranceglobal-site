# Public Website v28 — Public UX Audit

Scope: public-facing website QA following the v27 visual baseline.

Resolved in this release:
- Remove internal legal-review notes from public Terms of Use and Privacy Policy pages.
- Make all Maritime Capabilities cards actionable and route them to the most relevant existing industry, service, training, government, or contact page.
- Add a generated-site UX validator that blocks placeholder/dead anchors and internal-only legal-review language from public HTML.

Non-regression boundaries:
- No new award, endorsement, accreditation, licensure, or universal-qualification claims.
- No form schema, API contract, or Cloudflare architecture changes.
- Existing public qualification notices remain where they communicate legitimate scope boundaries rather than internal review state.
