## Purpose
This library defines and governs how Safety Assurance Global content is authored, reviewed, approved, updated, and archived. It provides a controlled standards set for editorial quality, metadata consistency, trademark usage, workflow compliance, and auditability.

## Repository Location
This governance library is maintained in the repository path:
- /docs/content/

All governance standards and related operational controls for content are stored in this location.

## How Documents Are Maintained
- Governance documents are updated through standard repository pull request workflow.
- Changes must include rationale, impact, and related document updates where applicable.
- Higher-authority standards govern interpretation when conflicts arise.
- Approved updates are recorded in CHANGELOG.md.
- Quarterly review cadence applies unless an earlier trigger event requires immediate review.

## How New Standards Are Proposed
1. Create a proposal in a pull request with a clear problem statement and scope.
2. Identify affected standards, workflows, and downstream controls.
3. Provide draft text and implementation impacts.
4. Route for required technical, legal/regulatory (if applicable), and executive review.
5. Merge only after executive approval and changelog update.

No new governance standard is active until approved and merged through controlled workflow.

## Relationship to the Website and Academy
- This library governs internal content operations that support website knowledge content quality.
- It defines standards used by teams preparing content for site publishing workflows.
- It supports consistency of Safety Assurance Global brand language, including academy-aligned terminology and governance expectations.
- It does not replace application code standards or deployment controls for the website platform.

## Governance Boundary
This directory is an internal governance foundation. It establishes rules and processes; it does not itself authorize direct publishing, deployment bypasses, or unmanaged content changes.
