## Standard Capitalization
Mandatory capitalization rules:
- Use title case for approved Category and Knowledge Domain values.
- Use sentence case for body copy headings unless a defined term requires title case.
- Capitalize formal role names only when used as defined governance titles:
	- Author
	- Technical Reviewer
	- Legal/Regulatory Reviewer
	- Executive Reviewer
	- Repository Maintainer
- Keep acronym capitalization fixed (for example, SAG, KPI, SOP).

## Reserved Terminology
Reserved terms require controlled usage and must align with governance definitions:
- Governed Content: Content subject to formal review and approval controls.
- Review Status: Lifecycle state used for governance gating.
- Executive Approval: Final approval checkpoint before publication workflow progression.
- Controlled Vocabulary: Approved term set enforced across metadata and body content.
- Publication Workflow: Authorized sequence from Draft through Archived.
- Evidence-Backed Claim: Claim supported by verifiable source material.

Reserved term constraints:
- Do not redefine reserved terms in article-level content.
- Use reserved terms consistently across metadata, headings, and body text.

## Naming Conventions
Naming conventions for governed content assets:
- File names:
	- Lowercase
	- Hyphen-separated words
	- No spaces
	- No special characters except hyphen
- Slugs:
	- Must match file naming pattern and remain stable once published
- Image names:
	- Descriptive, lowercase, hyphen-separated
	- Prefer topical naming (for example, `operational-readiness-overview.webp`)
- Tag naming:
	- Lowercase preferred
	- Keep concise and reusable
	- Avoid near-duplicate variants
