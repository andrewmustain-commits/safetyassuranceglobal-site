# Operational Authority — Final Release Gates

The release remains fail-closed until the applicable automated and human evidence is complete.

## Required qualification

1. Build and static validation pass on the exact release head.
2. Both required CodeQL matrix analyses—JavaScript/TypeScript and GitHub Actions—pass on the exact release head.
3. Public claims governance passes with no unsupported amplification.
4. Public UX and accessibility validation pass, including keyboard navigation, focus visibility, responsive reflow, and reduced-motion behavior.
5. Internal and governed external routes are validated.
6. Inquiry security boundaries remain intact; production delivery is not activated by this release.
7. Structured metadata and public indexing controls match the authorized release class.
8. No commerce, enrollment, credential issuance, public credential verification, external AI/API activation, or Institute authority change is introduced by implication.
9. Production smoke evidence is collected only under the separately authorized deployment boundary.

A green build is necessary but does not itself authorize a gated production capability.
